## Changes shipped

### Baseline fix (commit 1)
- `test_library_upload_creates_paper_and_assignment` mock now stubs httpx storage call (was hitting real URL → UnsupportedProtocol). Brings backend baseline from 78/79 to 79/79.

### Architectural debt closed (commits 2-4)
- **Dual Supabase client** (anti-pattern #2): background tasks now use `db.from_()` everywhere. Dropped `supabase` Python package from requirements.
- **Role helpers** (anti-pattern #5): `require_teacher` / `require_student` collapsed into `require_role(role)` factory; public names preserved.
- **Module-level settings** (anti-pattern #4): removed across 9 files; `ANON_HEADERS` removed from `auth.py`. Tests can now override settings cleanly.

### Reliability fixes (commit 5)
- **JWKS cache**: 10-min TTL with force-refresh-and-retry on verify failure. Previously a Supabase key rotation would have caused a wave of 401s before recovery.
- **JWT exception scope**: narrowed from `(JWTError, JWKError, Exception)` to `(JWTError, JWKError)`. Bare `Exception` was masking programming bugs as auth failures.
- **Session-start race**: extended `Result` with `status_code` field; only fall back to fetch existing session on HTTP 409 (unique-constraint violation). Real DB errors now surface as 500. Cargo-culted `isinstance(list)` guards removed.

### Response models (commit 6)
- 17 endpoints across sessions, dashboard, library, superpowers now have Pydantic v2 response models. Dashboard schema package created. Library `BrowseAssignmentInfo` helper added to match real return shape.
- Stable endpoints (assignments, classes, papers) intentionally NOT touched.

### Test coverage (commits 7-8)
- Backend: 21 new pytest cases covering rate limits, JWKS TTL, role factory, response shapes, session-start race regression guard.
- Frontend: 5 cleanup-verification cases locking May-1 fixes (jargon term, removed category field, email-confirmation panel, signup auth contract).
- A11y baseline via @axe-core/playwright on 8 pages — 3 critical violations fixed in source (file input aria-hidden, jargon button aria-label, sidebar toggle aria-label).
- Mobile (iPhone SE) and tablet (iPad) projects added to playwright config.
